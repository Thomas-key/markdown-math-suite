# Markdown Math Suite ・ Markdown 数学套件

在 Markdown 的数学环境（`$ … $` 行内、`$$ … $$` 行间）里输入触发词，立即展开成 LaTeX —— 记笔记不打断思路。

## 功能

- **环境门控**　只在数学环境里触发：行内 `$ … $`，行间 `$$ … $$`（这种 `$$` 要独占一行）。
- **跳过代码块**　``` / `~~~` 围栏代码块里的 `$` 不算数学，在里面也不会展开。
- **即时展开**　打完触发词当场替换，无候选栏、无延迟。
- **停靠点**　展开后光标停在待填参数处，`Tab` 依次跳转。
- **可嵌套**　展开出来的片段里继续打触发词，能接着展开。
- **后缀触发**　`xhat` → `\hat{x}`，先写字母再加修饰。
- **规则可改**　内置规则放在扩展目录的 `rules.jsonc` 里，可直接编辑（支持注释）；也可以在设置里覆盖或新增。

## 特色

- **补上原生片段的三个缺口**　原生片段无法判断数学环境、只能从字母开头匹配、后缀型触发词进不了候选栏 —— 本插件把三件事都解决了。
- **内置 111 条词尾规则 + 11 条正则规则**　覆盖希腊字母、幂/根/分式、集合关系、导数积分、极限求和、括号范数……（清单见文末「内置规则一览」）
- **两个触发词帮你起公式**　数学环境外敲 `mk` 得到 `$…$`，敲 `dm` 得到跨行的 `$$ … $$` 块。
- **两处可改，互不冲突**　`rules.jsonc` 管内置规则，设置管你自己的规则；同名键以设置里的为准。

## 数学环境怎么认

| 写法 | 算什么 | 说明 |
| --- | --- | --- |
| `$ … $` | 行内数学 | 只要这个 `$` 没被反斜杠转义，就算分隔符 |
| `$$` 独占一行 | 行间数学的开 / 关 | 一行去掉首尾空白后正好是 `$$` 才算 |
| 同一行的 `$$ … $$` | **不算**数学 | 这样写渲染不出来，所以也不当它存在 |
| `\$` | 字面美元符 | 不参与开关 |
| ```` ``` ```` / `~~~` 围栏 | 代码块 | 里面的 `$` 一律不算数学，也不展开 |

## 规则放在哪

|  | 位置 | 适合 |
| --- | --- | --- |
| 内置规则 | 扩展目录的 `rules.jsonc` | 成批整理、写注释、删掉不要的 |
| 你自己的规则 | 设置里的 `mdMathSuite.*` | 随手加一两条 |

两者会合并：**同名键用设置里的值，新键就是一条新规则。**

- `rules.jsonc` 支持 `//`、`/* */` 注释和尾随逗号。
- 改 `rules.jsonc` 后要**重新加载窗口**（命令面板 → `Developer: Reload Window`）才生效。
- 改设置则是即时生效，不用重载。

## 自定义

### 方式一：`rules.jsonc`（改内置规则）

```jsonc
{
  "inMath": {
    "sr": "^{2}",                   // 输入 sr → ^{2}
    "sq": "\\sqrt{$1}$0",           // $1 $0 是光标停靠点
    "//": "\\frac{$1}{$2}$0"        // 输入 // → \frac{_}{_}
  },
  "outMath": {
    "mk": "\\$$1\\$$0"              // 输入 mk → $…$
  },
  "inMathRegex": {
    "([A-Za-z0-9]+)hat$": "\\hat{{1}}"   // 输入 xhat → \hat{x}
  },
  "outMathRegex": {}
}
```

**替换内容按 LaTeX 原样写。** 唯一要注意的是这个文件是 JSON，所以每个字面反斜杠要写成两个：

| 想输出 | 文件里写 |
| --- | --- |
| `\alpha` | `"\\alpha"` |
| `\frac{a}{b}` | `"\\frac{$1}{$2}"` |
| 集合括号 `\{ \}` | `"\\{$1\\}"` |
| 矩阵换行 `\\` | `"\\\\"` |

**替换内容里的标记**：

- `$1` `$2` `$0` —— 停靠点（光标位置）
- `${1:默认值}` —— 带默认值的停靠点
- `\$` —— 字面美元符
- `{1}` `{2}` —— 正则捕获组（仅正则规则）

**块级规则**：替换内容以换行开头（`"\n..."`）时算块级规则；如果触发词本来就在行首，开头的那个换行会自动去掉。`dm` 就是这么写的。

### 方式二：设置（加自己的规则）

打开设置（`Ctrl + ,`），搜索 `mdMathSuite`：

| 设置项 | 说明 |
| --- | --- |
| `mdMathSuite.inMathRules` | 数学**内**规则：`触发词 → 替换` |
| `mdMathSuite.outMathRules` | 数学**外**规则 |
| `mdMathSuite.inMathRegexRules` | 数学内**正则**规则（后缀型，`{1}` 引用捕获组） |
| `mdMathSuite.outMathRegexRules` | 数学外**正则**规则 |

```jsonc
"mdMathSuite.inMathRules": {
  "sr": "^{2}",                // 输入 sr → ^{2}
  "sq": "\\sqrt{$1}$0",        // $1 $0 是光标停靠点
  "//": "\\frac{$1}{$2}$0"     // 输入 // → \frac{_}{_}
}
```

## 已知限制

- **正文里的美元符要用 `\$`。** `$ 5 $`、`价格 $5 到 $10` 这种会被当成数学环境 —— 分隔符只看有没有被反斜杠转义，不看贴不贴边。
- **行内 `` `code` `` 里的 `$` 不跳过。** 只有围栏代码块跳过；行内代码里的 `$` 请写 `\$`。
- **按 Enter 时位置会算错一行。** 扩展把 Enter 当成长度 1 的改动处理，取到的位置偏一行。实际影响很小（退格、粘贴这类根本不会进来）。
